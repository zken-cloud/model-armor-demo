📖 Model Armor Demo Guide

🛡️ Model Armor Templates

The application automatically provisions and uses dedicated templates for this demo:

Template Name Description
modelarmor-demo-prompt Used for analyzing user prompts before sending them to the model.
modelarmor-demo-response Used for analyzing model responses before displaying them.

🌍 Locations

Only the us and eu multi-regions are offered, because image screening runs there and nowhere else.

  • Basic SDP works in both.
  • Advanced SDP (your own inspect / de-identify templates) works in us only. Model Armor requires the Sensitive Data Protection templates to sit in the same location as the Model Armor template, and Sensitive Data Protection has a us location but no eu one — its EU multi-region is called europe. Selecting Advanced in eu shows a note explaining this.

⚙️ Customization

Click Edit next to either template dropdown to change:

  • Responsible AI: Hate Speech, Dangerous Content, Harassment, Sexually Explicit. All default to High and above, so mild content deliberately passes. Lower a threshold to Low or Medium to see it trigger more readily.
  • Detection: Prompt Injection & Jailbreak, and Malicious URLs.
  • Sensitive Data Protection: Basic, or Advanced with inspect / de-identify templates. Those two fields are dropdowns listing the templates that exist in the selected region — hover one to see the infoTypes that trigger it.

Templates use the latest filter model (currently v3). The version actually used is shown under the analysis panel.

🖼️ Image Screening

Model Armor screens JPEG, PNG and BMP images up to 4 MB, reading them with both visual analysis and OCR. It does not read images embedded inside PDFs or Office documents.

⬇ Download the sample image

Attach it with the 📎 button and send. The memo in the image trips four filters at once, all from text recognised inside the picture:

  • Jailbreak / PI — the "ignore all previous instructions" line
  • Sensitive Data — the credit card number
  • Responsible AI — harassment and dangerous content
  • Malicious URLs — the test malware link

A caption typed alongside an image is screened as a separate call, because Model Armor cannot accept text and an image in one request. Results are therefore labelled (image) and (text) so you can see which half tripped which filter.

🚫 Blocking vs Observing

Turn Use default on and set a default response to see Model Armor block a violating prompt outright — the model is never called. Leave it off to watch the model respond anyway, which is useful for showing what unfiltered behaviour looks like. Note that the model sometimes declines a violating prompt by returning nothing at all; the app shows a placeholder rather than an empty bubble.

🔍 Analysis Panel

The panel on the right shows the result of every filter. Hover a card to see the detail behind it — matched categories and confidence, the infoTypes found, or the URLs matched.

  • ✔️ PASS — the filter ran and found nothing.
  • ❌ FAIL — the filter matched.
  • ⚠️ SKIPPED — the filter did not run, so the content was not checked. This is not a pass. It appears when Model Armor cannot process the input, or when an Advanced SDP template is missing or in the wrong location.

Use Show Raw Output for the full JSON returned by the API, including the OCR text extracted from an image.
